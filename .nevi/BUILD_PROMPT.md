# 制作指示書: nevi-web-center

ネヴィがご主人さまと対話して整理した仕様です。**この文書を唯一の要件定義**として実装してください。
不明な点があっても質問せず、ここに書かれた方針から妥当に判断して進めてください。

## 0. 概要

概要: ブラウザ上からネヴィの状態（PCリソース、/taskの自動化リスト、Googleカレンダー、MCP接続状態）をリアルタイムに監視・操作できるダッシュボード。 進化への貢献: Discordだけでなく「WebUIからの指示受付（REST API/Webhook）」という新しいインターフェースがネヴィに生える！ パソコンの遠隔操作やタスク管理の視認性が一気に跳ね上がるよ！

## 1. リアルタイム監視と取得データ

・リアルタイム監視機能の仕様:
・PCリソース（CPU使用率、メモリ消費量、ディスク容量）のゲージ表示
・/task自動化リストの実行状況・タスク一覧・履歴カード表示
・Googleカレンダー連携の予定表示パネル
・MCP接続状態のステータスインジケーター表示
・specコマンド応答停止時のエラー検知、ログ表示、および調査・修正用プロンプト生成ウィンドウの配置

## 2. WebUIからの遠隔操作・制御機能

・操作・制御機能の全網羅:
・タスクの個別実行・停止・再試行ボタン（フロントエンド疑似操作）
・REST API / Webhook 形式のリクエスト設定・送信テストシミュレータ
・MCP接続のON/OFF切り替えおよび接続パラメータ変更UI
・Googleカレンダーイベント追加・編集の疑似UI
・specコマンド不具合用調査・修正プロンプトの生成・ワンクリックコピー機能
・ネヴィの提案: システム全体の緊急停止・全タスク一時停止ボタンの配置

## 3. 認証とセキュリティ

・ネヴィの提案: フロントエンド完結型パスコード保護（初回アクセス時のPINコード入力画面）
・ネヴィの提案: 設定値・APITokenのLocalStorage保存と一括クリア機能
・ネヴィの提案: Webhook URLおよび秘密鍵の非表示（マスク表示）切り替え機能
・サーバー通信不要のローカル疑似認証モードを実装

## 4. 技術スタックとシステム連携

・ネヴィの提案: 完全ローカル動作の HTML5 / Pure CSS3 / Vanilla JavaScript (ES6+)
・ネヴィの提案: 外部フォント・外部CDN・外部ライブラリ不使用（OS標準システムフォントスタック利用）
・ネヴィの提案: グラフ・アイコン類はすべてインラインSVGおよびCSSアニメーションで描画
・ネヴィの提案: 状態管理は LocalStorage と Custom Event パターンで構築

## 5. 画面レイアウトとUI/UX

・ネヴィの提案: ダークテーマ主体のサイバーダッシュボードデザイン
・ネヴィの提案: 背景色 `#0f172a`（深海ネイビー）、カード背景 `#1e293b`、枠線 `#334155`
・ネヴィの提案: アクセントカラー `#38bdf8`（シアンブルー）、成功色 `#22c55e`（ネオングリーン）、警告・不応答色 `#ef4444`（アラートレッド）
・ネヴィの提案: 視認性を重視したCSS Gridレイアウト（左側ステータス・右側操作・下部ログ）
・ネヴィの提案: カードごとの発光ホバーエフェクトおよびステータスバッジ配置

## 7. 実装ルール（必須）

- 静的Webサイトとして実装する
- `index.html` を必ずプロジェクトルートに置く
- 外部CDN・外部フォント・外部スタイルシートを使わない（自己完結させる）
  画像は inline SVG か data: URI で埋め込む
- レスポンシブにする。スマホで横スクロールが発生してはいけない
- `prefers-color-scheme` でライト/ダーク両対応にする
- セマンティックなHTMLと十分なコントラストを確保する
- ダミーテキスト（lorem ipsum）ではなく、意味のある実際の文章を書く
- 上記「掲載する情報」に無い連絡先・価格・実績を勝手に作らない。
  必要なら `（要差し替え）` と明示したプレースホルダにする
- 実在の人物・団体について事実を捏造しない
- ファイル数は必要最小限にする

- [ ] `index.html` がプロジェクトルートにある
- [ ] 「3. ページ・セクション構成」の項目がすべて実装されている
- [ ] 「5. 必要な機能」がすべて動く状態になっている
- [ ] 幅 375px で横スクロールが発生しない
- [ ] ライトモード・ダークモードの両方で文字が読める
- [ ] lorem ipsum などのダミーテキストが1文字も残っていない
- [ ] 外部への通信が1つも無い（CDN・Webフォント・外部画像すべて自己完結）
